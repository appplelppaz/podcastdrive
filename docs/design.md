# 聞き流しアプリのデザイン

frontend-design スキル（`.claude/skills/frontend-design/SKILL.md`）の手順で決めたもの。

## 題材・使う人・画面の役目

- 題材: 中国語・スペイン語・フランス語・英語のポッドキャストを、1文ずつ「原文 → 日本語訳 → 語彙・文法 → 原文」で聞く。
- 使う人: 運転中・ランニング中に、画面を一瞬だけ見る日本語話者の学習者（本人）。
- 再生画面の役目: いま流れている文と、その訳・説明が一目で読めること。それ以外は出さない。
- 一覧・設定の役目: 教材を取り込み、続きから始め、読み上げの回数と速さを決める（止まっているときに使う）。

## 方向

夜の車のメーターの琥珀色の照明。夜に目がくらまない暖かい光を、黒ではなく深い藍色の上に置く。
「いま読んでいる語」だけが琥珀色に灯り、読み終えた語は白く、まだの語は霞んだ青灰色。

## 書体

- Atkinson Hyperlegible（Braille Institute が読みやすさのために作った書体。`app/fonts/`、SIL OFL）を画面の英語と原文に使う。
  日本語の訳・説明（`lang="ja"`）は端末の日本語書体。
  I・l・1、O・0 の見分けがつき、一瞬で読む用途に合う。1つの書体だけを使い、太さ（400・700）で役割を分ける。
- 日本語は Hiragino Sans、中国語は PingFang SC / Hiragino Sans GB（端末の書体）。
- 大きさ: 再生画面の原文 30〜50px（画面に合わせる）、訳・説明 22〜36px。一覧の見出し 26px、本文 17px、補足 15px。

## 画面の構成（3版目: 面をやめて、文字と線だけ）

持ち主の希望「もっとシンプルでかっこよく」を受けて、カード（角丸の面）をすべてやめた。
深い藍色の地の上に、文字と細い線だけを置く。線は飾りではなく**進み具合**で、聞いたところまで琥珀色になる。

**画面の言葉は英語で、できるだけ短く**（持ち主の決まり。`CLAUDE.md`）。日本語は教材の訳・説明だけ。

```
ホーム                        エピソード                  再生（変えない）
Listening            ⚙       ‹                           ‹      Ⅱ
English  Demo Radio          English  Demo Radio
Weather and travel           Morning market check          Many shoppers
                             Sentence 3 of 4               are looking…
Heavy rain is expected
in the north.                (Continue) Restart      🗑    ┃多くの買い物客…
                             ▓▓▓▓▓▓▓░░░░░░░░░░░░░░
(Continue) Sentences  2 of 3 0:00 Good morning …
▓▓▓▓▓▓░░░░░░░░░░░░░░░░░           おはよう…
                             ─────────────────────
Episodes              Add    0:07 Many shoppers …  ← 止めた文は琥珀色
Weather and travel   🗑 (▶)
Demo Radio  Sentence 2 of 3
▓▓▓▓▓░░░░░░░░░░░░░░░░░░
```

- **ホームの最初は「続きから」**: 止めた文そのもの（原文）を、この画面で一番大きな文字で見せる。飾りの線や面は付けない。
- **エピソードの行**: 題名（タップで文の一覧）・ごみ箱・丸い再生ボタンの1行。再生ボタンは続きがあれば続きから。
  最初からやり直す Restart はエピソードの画面に置く。行の下の線が進み具合。
- **Add** は見出し「Episodes」の右。取り込みの結果はその下に出す。
- **言語の切り替え**: 文字だけのタブ。選んでいる言語に琥珀色の下線。
- **エピソード画面**: 題名・進み具合・操作の1行、その下に文の一覧（時刻・原文・訳）。止めた文は原文を琥珀色に。
- **設定**: 面をやめ、小さな見出し（Playback / Read aloud / Voice / Device）と線で区切った行。
  Voice では端末の日本語の声を選んで Test で聞ける。
- 左揃え。数字は等幅の並び（`tabular-nums`）。

## iPad 版（`/ipad/`）

同じアプリ・同じ保存データ（教材・設定・再生位置）を、iPad の広い画面に合わせて並べ替えたもの。
URL は `https://podcastdrive-app.vercel.app/ipad/`（`vercel.json` の書き換えで同じファイルを配り、ホーム画面用の設定だけ別）。
`?layout=ipad` でも同じ見た目になる（確認用）。

```
┌───────────────┬──────────────────────────────────┐
│Listening    ⚙ │English  Demo Radio                │
│┌─────────────┐│Morning market check               │
││Continue 面  ││▓▓▓▓▓░░░ Sentence 3 of 4           │
│└─────────────┘│[Continue] Restart                 │
│All Chinese …  │Sentences                          │
│┌ 教材 ──────┐│0:00 Good morning …  おはよう…      │
│└─ (選択中) ─┘│┃0:07 Many shoppers … 多くの…       │
│[Add episodes] │                                    │
└───────────────┴──────────────────────────────────┘
```

- 左（380px）に一覧、右に選んだエピソードの文の一覧（または設定）。画面を行き来しない。選んでいる教材は題名を琥珀色にする。
- 再生画面は iPhone と同じ並び（左揃え・ほぼ全幅・文は縦の中央）のまま、画面に合わせて大きくする（持ち主の希望）。
  幅 900px・高さ 700px 以上の画面（iPad Pro 12.9 など。`/ipad/` でなくても）では、原文 56〜92px（12.9 では約 70px）、
  訳・説明 38〜64px（約 48px）、戻る・一時停止の印も大きくする。一覧・エピソード・設定の文字も一段大きくする。
- 縦向き（幅 820px）でも同じ2列。左右それぞれが別にスクロールする。

## 原則

- 目立たせるのは「いま読んでいる語」の琥珀色の1か所だけ。ほかは静かにする。
- 大文字だけのラベル、「A · B — C」のようにつないだ情報、飾りの影やグラデーションは使わない。
- タップ・スワイプなどの操作では、字幕に重なる表示を出さない（持ち主の希望）。伝えるのは軽い振動と、一時停止中の上の「Ⅱ」だけ。`prefers-reduced-motion` を守る。
- 長い原文・訳・解説が画面に収まらないときは、字幕の枠を縦にスクロールできる（横スワイプ・タップ・長押しはそのまま）。戻るボタンと「Ⅱ」は枠の外に置き、スクロールした文字が重ならないよう枠の上端を薄くぼかす。読まれている単語や新しく出た説明が画面の外なら、そこまで送る。
- エピソードの削除は、一覧の行とエピソード画面で、再生と同じ行にごみ箱の印だけで控えめに置く（`aria-label="Delete"`）。消す前に確認し、音声・字幕・再生位置もいっしょに消す。

## 見直したこと（既定のデザインになっていないか）

- 3版目: 2版目は「同じ角丸の面を並べ、どれにも同じ丸いボタン」で、スキルが挙げる SaaS カードの見た目に寄っていた。
  面をやめ、区切りの線そのものを進み具合にした。琥珀色は「再生」「いまの場所」「進み具合」だけに使う。

- 2版目: ホームを同じ形のカードの並びだけにすると、スキルが挙げる「同じ角丸カードを並べただけ」になる。
  一番上に「続きから」の大きな面（止めた文の原文そのもの）を置き、カードの並びは静かな一覧にして、強弱をつけた。

- 以前の画面は「ほぼ黒の地に明るい青の1色」で、スキルが挙げる典型的な既定の見た目だった。
  地を深い藍色に、強調色を題材（夜のメーターの照明）から来る琥珀色に変えた。
- 見出しの「LIBRARY」「SETTINGS」（大文字のラベル）と、「Demo Radio · 3 sentences — Last: …」のつなぎ方をやめ、
  文の形の見出しと、行を分けた情報にした。

## アイコン

音（琥珀色の波形）が字幕（語の長さに切れた文字の線）に変わる形。「聞く」と「字幕で読む」を、文字を使わずに表す。
地は深い藍色で、メーターの照明のように中央がわずかに明るい（放射状のぼかし1つだけ）。
ホーム画面の小さな大きさでも形が分かるよう、図は全体の8割近くまで大きくしている。
`app/icons/icon.svg` が元で、PNG はそこから作る（`node tools/make_icons.cjs`）。
